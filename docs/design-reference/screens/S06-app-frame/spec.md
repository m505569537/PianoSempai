## 视觉规范

- Tab bar：高约 56 + 安全区；`#1C1917` 底（可加顶部 1px `#332D29`），图标 24pt，文字 label-sm；激活琥珀（图标+文字+图标上方/下方 4pt 圆点二选一，用圆点）；未激活 muted。
- 五 tab 顺序与图标写死：今日(日历) / 曲库(翻开乐谱) / 练习室(钢琴键盘) / 档案(归档盒/历史时钟) / 我的(头像)。**第 4 tab 是"档案"**——Stitch 多次画成商城/社区/榜单/收藏/统计/训练营，全部作废。
- FAB：胶囊，elevated 表面 `#2D2724` + 琥珀 0.18 描边 + 暖色底辉，猫脸线稿 18pt 琥珀 + "问 Neko" title-md；位于 tab bar 上方 12pt、右边距 20。
- 连接胶囊：右上，描边胶囊 label-md；已连接=绿点；未连接=红点+muted 文字；MIDI 断开练习时升级为顶部全宽红横幅（见 S11-disconnected）。

## 交互态（框架级视觉）

- 切 tab：图标/文字变色 150ms；无切换动画外的装饰。
- FAB 在全屏练习室/视频播放/弹层页面隐藏或让位（各页 spec 注明）。
- 今日/练习室 tab 未连接设备时，页内主 CTA disabled + 引导去 S03（不弹强制页）。
