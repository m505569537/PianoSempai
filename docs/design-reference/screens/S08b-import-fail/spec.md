# S08b 乐谱导入失败（Alert/Sheet）

- 本地参考图：`design/samples/S-import-fail.png`
- Status: Final

## 用途一句话

MusicXML/.mxl/.mscz/.mid 解析失败时给出具体错误位置与代码，以及可操作的两条出路；不静默跳过。

## 首屏布局（中央 dialog）

```
│ scrim
│ ┌────────────────────────────┐
│ │ [⚠ 红色文档图标]               │
│ │ 这个文件没能解析                │
│ │ summer_扒谱.mxl · 2.3MB        │
│ │ ┌ 错误详情（surface-low）─────┐│
│ │ │ 第 34 小节 · 声部缺少闭合标签  ││
│ │ │ 错误代码：PARSE_XML_34        ││
│ │ └────────────────────────────┘│
│ │ 在 MuseScore 里打开这个文件，检查 │
│ │ 第 34 小节后另存为 .musicxml 再试。│
│ │ · 支持 .xml / .mxl / .mscz / .mid│
│ │ · PDF 请放进 PDF 资料库（不能跟弹）│
│ │ 〔查看导入帮助〕〔重新选择文件〕〔我知道了〕│
│ └────────────────────────────┘
```

## 视觉规范

- Dialog 宽 320，圆角 12；错误详情卡等宽小字（mono 错误码）。
- 三按钮横排或上下：帮助（幽灵）、重新选择（描边）、知道了（琥珀文字）。
- 不用系统通用 Alert（要承载详情与帮助）。

## 交互态

- 「重新选择」直接开 Files；「导入帮助」跳 S10 的"如何获取可练谱"区。
- .mscz 解析失败时错误详情额外提示"MuseScore 工程文件兼容有限，可导出 .mxl"（M2 spike 结论承接）。

## 红线/事实

- 不假装导入成功；不把失败文件塞进曲库。
