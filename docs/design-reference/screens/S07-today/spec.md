## 视觉规范

- streak：7 圆点直径 10，间距随屏宽均分；点下可 tooltip 显示该日时长（本画布内）。
- 时长选择：三等分按钮（高 44），选中琥珀填充深字，未选 surface-low 描边。
- 任务卡：左侧 3pt 类别竖条（热身=success 绿、主菜=琥珀、奖励曲=`#8FA3B8` 蓝灰），标题 title-md，副信息 body-sm muted；完成卡整体降透明度 0.55 + 右上绿 ✓；错误热点 chip：琥珀描边小号。
- 周进度条：轨道 `#3D3531` 高 4，填充琥珀，右值 label-md tabular。
- 热身未完成时点主菜「开始」→ S07c 强开弹层（不静默放行，红线 6）。

## 交互态

- 切换时长：三段卡时长副标题联动（热身固定 8–12，主菜/奖励按剩余时间分配重算文案，视觉上只改数字）。
- 奖励曲卡永远可进（无门禁、无进度条件）。
- 下拉刷新同步 take 存储（纯本地，无 loading 骨架外的网络态文案）。
