# S15 机位校准向导（主动录像流程）

- Screen ID: 见 Stitch 画布"机位校准"（figaro 竖屏）
- 本地参考图：`design/samples/S15-camera-calib.png`
- Status: Final

## 用途一句话

"录给 AI 看"独立流程的前置：4 步向导（摆放/取景/试录/完成），用取景反馈让用户把手机摆到能看见手的位置，用户不用记规则。

## 视觉规范

- 预览区：16:9 或 4:3 按真实取景，圆角 8；取景框琥珀 2pt 虚线 + 角标"手部区域"；骨架点 success 绿连线（校准阶段），正式录制分析标注用琥珀/红。
- 反馈 chips 浮于预览左下：绿=通过项、琥珀=动作指导（用动词短句："向左转一点 / 再靠近 10cm / 压低一点"）。
- 三条摆放提示 body-sm muted。
- 免责卡：surface-low + body-sm，琥珀左缘。
- 底部：跳过幽灵（左），主按钮（右）。

## 交互态（本画布流程视觉）

- step1 摆放：静态示意图（侧视简图：手机-琴-手的位置关系）。
- step2 取景：实时骨架 + 反馈；全部必检项绿（键盘完整 / 双手在框 / 指尖不切边）后主按钮变"下一步：试录"。
- step3 试录：5 秒录制回放 + 骨架，确认。
- step4 完成：✓"机位已记住"，进入录制待命（不自动开始录）。
- 任何步可跳过；跳过则录制前仍会检查最低条件（键盘可见），但不阻止。

## 红线落点

- 只在主动流程内使用相机；免责声明常驻（红线 4/5）。
- 手型永不进门禁的话在本流程第一步就出现，且每个含手型结果的页面重复可达。
