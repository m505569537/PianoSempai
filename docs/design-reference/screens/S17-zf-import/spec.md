# S17 Zf 月度录像导入

- Screen ID: 见 Stitch 画布"导入月度录像"
- 本地参考图：`design/samples/S17-zf-import.png`
- Status: Final

## 用途一句话

每月一次从相册选择 Zf 拍的练琴视频导入本机永久归档；不上传、不判分、不自动分析手型。

## 首屏布局

```
┌ ‹ 返回
│ 导入月度录像 · 2026 年 9 月
│ 每月一次，把相机拍的练习视频存进本机，
│ 永久保留。不上传、不判分。
│
│ 已选 3 段 · 12分40秒 · 1.8GB · 本机剩余 24GB
│
│ ┌────────────────────────────┐
│ │ [缩略] 9/14 19:52  4分02秒  ☑ │
│ │ [缩略] 9/07 20:06  3分51秒  ☑ │
│ │ [缩略] 9/01 19:44  4分47秒  ☐ │
│ │ （9/21 灰显：未到日期/未拍摄）  │
│ └────────────────────────────┘
│ 导入后可在档案里按月回看；手型标注需要
│ 你主动发起，不会自动分析。
│
│ 〔全不选〕        〔导入所选 3 段〕
└ 无 tab
```

## 视觉规范

- 行：左缩略（16:9，64 高），右日期/时长 body-sm，复选框 22pt；选中琥珀。
- 汇总信息卡：surface-low，三组 tabular 数字等宽排列。
- 底部主按钮随选择数更新；未选时 disabled。
- 空间不足时汇总行变 danger 并禁用导入，给"管理存储"文字链（去存储占用设置）。

## 交互态

- 导入中：进度条 + "正在复制到本机，不压缩原画（可在设置改）"；可后台，完成发本地通知。
- 导入后视频归属"月度录像"集合，档案按月时间线可见；默认不进手型分析。
- 主动标注入口：档案视频详情里"对这一段做手型标注"（端上 MediaPipe，走 S16 呈现）。

## 红线落点

- "不上传、不判分"必须在副标题；与日常"录给 AI 看"（S15/16/18b）是两个独立事件。
