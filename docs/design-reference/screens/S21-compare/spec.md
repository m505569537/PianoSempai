## 视觉规范

- A/B 色：A 琥珀（本次/较新）、B 蓝灰 `#8FA3B8`（旧次），图例 label-sm。
- 雷达双多边形填充各 15%，边 1.5；参考网格同 S05。
- 速度图：参考虚线 muted；21 小节降速点加竖线与数值气泡。
- 热力双条：两行标签 A/B 在左，色阶同 S13；右侧"共 N 处"tabular。
- delta 行：左指标 body-md，右"旧 → 新"tabular + 绿 ↑（退步则红 ↓，仍只陈述）。
- CTA 跳 S12（预填 21 小节循环），不跳过关判定。

## 交互态
