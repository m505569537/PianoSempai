## 视觉规范

- 步骤指示器：三段等长横线 + 小圆点；已完成段琥珀实线，当前段圆点琥珀实心带轻辉光，未到段 `#3D3531`；步骤数字 label-sm。
- 设备卡：左 40pt 图标容器；主标题 title-md，副信息 body-sm muted；右侧连接按钮 64 高描边。
- 扫描行：图标旁三点呼吸动画（依次亮琥珀，1.2s 循环）。
- 帮助卡：无强调底色或 surface-low，项目符号用 "·"。

## 交互态（本画布视觉）

- 搜索中：呼吸三点；找到 V70 后设备卡滑入（150ms）。
- 点「连接」：按钮变 spinner「连接中」；成功后整卡描边变 success 绿、行尾变绿 ✓「已连接」，CTA 变亮。
- 连接失败：设备卡下出现一行 danger body-sm「连接失败，再试一次」，不弹吓人 Alert。
- BLE 丢 Note Off/断线等运行态不在本页（见 S11-disconnected 与 MIDI 诊断页）。
