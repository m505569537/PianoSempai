# S24 MIDI 诊断

- Screen ID: 见 Stitch 画布"MIDI 诊断"
- 本地参考图：`design/samples/S-midi-diag.png`（高清 S-midi-diag-hd.png 已验无乱码）
- Status: Final

## 用途一句话

实时验证 V70 的音高/力度/踏板/时间戳信号，排查连接问题；信息不上传。

## 首屏布局

```
┌ ‹ 返回
│ MIDI 诊断
│ ┌ 设备 ─────────────────────┐
│ │ [键盘图标] 特伦斯 V70 · 已连接    │
│ │ BLE-MIDI │ 延迟 ~12ms │ 刚刚 │ 1284 事件 │
│ └────────────────────────────┘
│ ┌ 实时信号（弹一个音试试）────────┐
│ │ 音高  C4 · MIDI 60      [────●]│
│ │ 力度  96 / 127          [──●──]│ ← 条形随弹奏跳
│ │ 踏板  CC64 = 127（踩下） [●────]│
│ │ hostTime  128492.441 ms        │
│ └────────────────────────────┘
│ 〔重新校准力度（2 分钟）〕
│ ┌ 排错 ─────────────────────┐
│ │ · 断连频繁：靠近一点或用 USB-B 方口│
│ │ · 没信号：确认蓝牙 MIDI 权限已开  │
│ │ · 力度不动：在琴上检查力度感应开关│
│ └────────────────────────────┘
│ 诊断信息不会上传。
└ 无 tab
```

## 视觉规范

- 设备卡四格读数：label-sm muted + 值 tabular；连接点 success。
- 信号条：轨道 4px，实时值琥珀，未弹奏时归零灰；踏板只有 0/127 两态（开关样式）。
- hostTime 等宽数字 body-sm。
- 排错卡 surface-low，"·"引导。
- 脚注 muted 11 居中。

## 交互态

- Note On 到达：对应条 100ms 内弹起再回落；最近 1 个音名放大显示。
- 无事件 3 秒：提示"还没收到信号"muted 条（不是错误）。
- 校准入口 → S03 第 3 步同款力度校准流程（最弱/最强/舒适三档采样）。
