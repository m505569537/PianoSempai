# S26 导出我的全部数据

- Screen ID: 见 Stitch 画布"导出我的全部数据"
- 本地参考图：`design/samples/S-export.png`（高清 S-export-hd.png 已验）
- Status: Final

## 用途一句话

生成可恢复的全量 zip（课程状态/take 元数据/MIDI/乐谱/笔记；视频可选），或仅导出 PDF 报告；本地分享保存。

## 首屏布局

```

│ 导出我的全部数据

│ 换新机时可以完整恢复。
│ ┌ 导出内容 ─────────────────┐
│ │ ☑ 课程状态与路线     12 KB     │
```

## 视觉规范

- 清单行：复选 22pt + 名称 + 右值 tabular muted；视频行未选时整行 0.6 透明。
- 单选同全局；安全卡 surface-low。
- 合计行 title-md tabular；生成中变进度（"正在打包 54MB…"系统进度条，可取消）。
- 完成后走系统分享面板（存"文件"/AirDrop 给自己）。

## 交互态

- 勾选视频 > 剩余空间：行内 danger，禁止导出。
- 恢复：选择 zip → 显示将覆盖的内容差异计数 → 二次确认（自动先在本机生成恢复前快照）。

## 红线/范围

- 视频默认不勾；Key 永不入包；zip 为开放格式（MIDI/MusicXML/JSON/PDF/mp4），无账号绑定。
