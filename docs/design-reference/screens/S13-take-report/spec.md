## 视觉规范

- 弱总分：serif tabular 44，后面不跟"/100"大字竞争；唯一解释文字紧贴其下 label-sm muted。
- 雷达同 S05；热力条：8 段（每小节一段），强度色阶；超阈值用 danger；小节数字 label-sm 等距。
- 偏差折线：0 轴横线，±50ms 容差带用琥珀 10% 横向色带；点在带外变红；标注气泡 label-sm 带引线（如"+120ms"）。
- 错音清单：行左小节号 mono/serif 琥珀固定宽 56；正文 body-sm；折叠用 chevron 旋转。
- 速度力度卡：两列等宽数值。
- 置信度卡：surface-low，全部 label/body-sm muted。
- 底部三按钮：前两个描边次按钮（等宽），"问 Neko"文字/琥珀；不出现"分享给老师/好友"。

## 交互态

- 点热力小节 → 错音清单滚动定位并高亮该行（本画布）；点错音行 → 可"只听期望/我弹的"（MIDI 回放，v1 可只放期望音）。
- 低置信态：置信度行改为 amber/danger"有 6 个音符没听清，这一段结论仅供参考"（红线 2：没把握明说），雷达受影响维度加虚线。
- 有视频的 take：置信度卡显示"侧拍 0:32 · 手型观察 3 条"入口 → S16。

## 红线落点

- 弱总分 + 脚注（不作过关依据）；过关判定不在本页发生。
- 脚注逐字"对齐置信度高 · 踏板已计入判分"（样图曾误作"解答已计入得分"）。
- 时长示例 2分14秒（样图误作 34 秒）。
