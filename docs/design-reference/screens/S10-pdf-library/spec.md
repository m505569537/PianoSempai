PDF 谱的只读资料库 + "如何获取可练谱"教育区；明确 PDF 不跟弹不判分。

## 视觉规范

- 提示卡：surface-low + 左缘 3pt 琥珀；body-sm。
- 文件行：左红色文档类型图标容器（PDF 红 `#C97064`），名单行，副信息 muted；右 chevron；滑动可删除（删除走确认）。
- 教育区为有序列表，数字用 serif tabular 琥珀。
- 点 PDF → 系统 QuickLook/PDF 阅读器风格全屏查看（仅缩放/翻页，无标注）。

## 交互态

- 导入走 Files 选择器；多选。
- 空态："还没有 PDF。导入的 PDF 只能在这里翻看。"
- 与 S08 曲库互斥：PDF 永远不出现可练/判分入口。

## 红线落点

- 不做 OMR（不做清单）；不做 PDF 跟弹。顶部提示和底部脚注双声明。
