## 用途一句话

用户自配火山方舟 API Key（iOS Keychain 存储、掩码显示、可替换/删除），模型版本可更新，连接测试。

## 视觉规范

- Key 行：等宽圆点掩码 + 末 4 位明文；眼睛图标切换显隐（显态 30s 自动回掩码）；✕=删除。
- 替换：弹输入 sheet（粘贴/扫码/手动），保存即校验（调一次最小请求）。
- 配置行：左 label muted，右值 body-md tabular/mono 域名。
- 删除为危险操作：二次确认 sheet，默认焦点取消。
- 测试结果：行内 success/错误；错误显示原始错误码（如 401/网络），不吞错。

## 交互态

- 未设置态：状态卡变琥珀引导"还没有 Key"，输入框直接露出，附"如何在火山方舟开通"折叠说明（外部 Safari 链接，不开内嵌浏览器登录）。
- `/api/coding` 代码套餐入口不可用于本功能；标准 `/api/v3` 由配置承载（P3 spike 确认）。

## 红线落点

- Key 不入日志/导出/总结；内存外只在 Keychain（凭据铁律）。
- 唯一 AI 供应商，本页无"切换供应商"。
