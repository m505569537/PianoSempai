## 视觉规范

- 三张权限卡同构：左图标圆形容器 40pt（surface-high + 琥珀图标），标题 title-md，说明 body-sm text-body；卡底一行：左语义 chip，右系统风按钮（去授权=琥珀小填充；稍后再说=幽灵；允许通知=次按钮描边）。
- 安全卡：底色 surface-container-low，左侧 16pt 盾牌；正文 label/body-sm text-body。
- 卡间距 12，整组距底部 CTA 24。

## 交互态（本画布视觉）

- 「去授权」点击后呈现系统蓝牙授权弹窗（系统组件，不自定义）；返回本页后该行 chip 变「已授权」success 绿、按钮消失变 ✓。
- 「允许通知」同理；「稍后再说」该行保持原样可后补。
- 蓝牙未授权时底部 CTA 可点但进入 S03 后显示未授权引导（不锁死，允许先逛）。

## 红线落点

- 相机卡必须出现「仅在主动录制时」且文案明示日常不录不音（红线 4）。
- 安全卡必须点名"火山方舟"（不得写"云端""AI 服务器"等模糊词）。
- Info.plist 用途串与卡片文案一致（NSBluetoothAlwaysUsageDescription / NSCameraUsageDescription / NSMicrophoneUsageDescription）。

## 文案锁定

- 三卡标题、chip、安全卡、CTA「继续：连接电钢琴」逐字。样图曾把"和"字附近画糊、"不录像、不录音"画成"不录音，不录音"，以本 spec 为准。
