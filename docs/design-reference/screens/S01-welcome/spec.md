## 视觉规范（本屏特有，其余见 foundation）

- 徽标：纯描边琥珀（不用填充、不闪光、不卡通），约 120–140pt 见方，可带极弱琥珀径向光晕。
- 三特性行：高约 44，图标 22pt 琥珀线稿；主文案 body-md text-primary；右侧英文小注 label-sm text-muted/字距 0.08em（SIGNAL / OPUS / LOCAL，装饰性，可在实现中省略但不得改成中文）。
- 「开始」按钮下方免责小字最多两行，行高 16。
- 全页无卡片容器（除特性组可选一个无描边分组），靠留白分层。

## 交互态

- 徽标可做极慢琥珀呼吸（透明度 0.85↗1.0，周期 ≥3s），按按钮前结束；无其他动效。
- 「开始」pressed：标准主按钮态。
- 无横屏。

## 红线落点

- 无登录/注册/手机号/第三方账号入口（红线：零账号）。
- 按钮下小字是视频最小必要 + 手型不裁判两条红线的首次告知，不可删。

## 文案锁定

- 标题、slogan、三特性、按钮、两行小字、版本行全部按 ASCII 中逐字实现。
