# S14 自由弹奏

- Screen ID: 见 Stitch 画布"自由弹奏"（figaro 竖屏）
- 本地参考图：`design/samples/S14-freeplay.png`
- Status: Final

## 用途一句话

不跟谱、不打分的即兴弹奏沙盒：MIDI 钢琴卷帘实时记录，弹后可写一句话存为自由 take。

## 首屏布局

```
┌ 状态栏  ‹ 返回                    历史录音 ⇪
│ 自由弹奏              ← serif
│ ┌────────────────────────────┐
│ │     钢琴卷帘音符流（竖向/横向滚动） │ ← 占 ~38%
│ │  随便弹，不打分 · 音符只记录在本机 │ ← 居中 muted
│ └────────────────────────────┘
│ 本次时长 12:34    音符 486
│ ● 录制中（仅 MIDI）        ← 红点 + label，强调不是视频
│
│ 这次弹了什么？
│ ┌────────────────────────────┐
│ │ 例如：瞎弹了一段菊次郎的夏天     │ ← 多行输入
│ └────────────────────────────┘
│
│ 〔节拍器〕      〔丢弃〕
│ ┌────────────────────────────┐
│ │        结束并保存             │ ← 琥珀主按钮
│ └────────────────────────────┘
└ 无 tab
```

## 视觉规范

- 卷帘：深色底（surface-low），音符块琥珀 8px 圆角，从右向左（或下向上）流动；无键盘对错着色。
- 录制指示：红点直径 8 呼吸（1s），文字 label-md；明确"仅 MIDI"。
- 输入框：标准输入规范，3 行高。
- 底部三操作：节拍器图标钮、丢弃危险文字钮（左对齐）、主按钮全宽在下。

## 交互态

- 进入即开始捕获 MIDI（不需要先点录音）；后台仍受 App 音频会话管理。
- 「丢弃」走危险确认（删除后不可恢复，默认焦点在取消）。
- 保存后写入 take（类型=自由弹奏，无评分、无课程关联），跳档案；输入为空时用"自由弹奏 · 时间"作标题。
- 历史录音：档案 tab 中自由弹奏筛选；本页右上角进入同筛选视图。

## 红线落点

- 全页无评分、无错音提示、无门禁；无摄像头入口（自由弹奏默认纯 MIDI）。
