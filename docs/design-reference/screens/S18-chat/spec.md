# S18 问 Neko 对话

- Screen ID: 见 Stitch 画布"问 Neko"（figaro 竖屏）
- 本地参考图：`design/samples/S18-chat.png`
- Status: Final

## 用途一句话

带弹奏上下文的 AI 助教对话：回答必须引用 take/小节/偏差；支持发视频片段（必经 S18b 裁切确认）；低置信明说。

## 首屏布局

```
┌ ‹ 返回
│ 🐱 问 Neko
│ 〔拜厄45 · 今天20:31 的 take〕 ← 上下文 chip（可换/✕）
│
│ 气泡区（我=右侧琥珀深字；Neko=左侧 surface 卡）：
│ 我：21 小节我总卡，怎么办？
│ Neko：你在 21 小节的转指平均慢了 120ms，
│ 主要是 3 指转 1 指时手腕没提前带过去。
│ 建议 ♩=60 单手练 4 遍，每遍之间甩手 10 秒，
│ 把转换做到 ±40ms 以内再合手。
│   〔take·今天20:31〕〔小节21·+120ms〕  ← 证据引用 chips
│ 我：[视频消息] 侧拍 0:32 ▶
│ Neko：这段你的右手手腕被身体挡住了一点，
│ 我看不清转指动作，不能确定问题在哪。
│ 可以重新按机位向导摆一下再拍吗？
│   〔重新校准机位〕（琥珀描边小按钮）
│
│ Neko 只有建议权，过关由你的弹奏数据判定。  ← 底部常驻脚注
│ ┌──────────────────────────┐ [＋][🎤]│ ← 输入栏
│ │ 问点什么…                  │
│ └──────────────────────────┘
└ 无 tab（从 FAB/报告/练习室进入）
```

## 视觉规范

- 我的气泡：琥珀底深字，最大宽 78%，右对齐圆角 12（尾角小）；Neko 气泡：card 表面 + 发丝边，左对齐。
- 证据 chip：消息气泡下方，描边小胶囊 label-sm，可点跳 S13 对应小节/报告（跳转见导航 doc）。
- 视频消息：缩略条（首帧 + 时长 + ▶），点击 → S16；上传前一律先经过 S18b sheet（不直接发）。
- 上下文 chip：顶部吸附，显示绑定数据源；✕ 后为"无 take 上下文的自由问答"，此时 Neko 回答需自述未看数据。
- 输入栏：底部安全区上，+ 号展开附件（视频片段/图片/take），麦克风=语音输入（系统，不做语音评判）。
- 打字等待：三点呼吸；失败态气泡"没连上，点此重试"，不吞消息。

## 交互态（视觉）

- Neko 回答中正在检索本地 take 时气泡内显示"在翻你最近的 take…"细进度。
- 低置信/看不清：整段气泡前缀 warning 小图标，禁用"采纳为计划"类按钮（本应用无此按钮，AI 不写状态）。
- 长回答折叠：超 6 行渐隐 + "展开"。

## 红线落点

- 脚注"Neko 只有建议权…"常驻（红线 3）。
- 看不清必须明说，禁止编造手型/错音结论（红线 2），视觉样例即此屏第二组问答。
- 视频发送必经裁切 + 服务商明示（S18b，红线 4）。
- 无分享到社区/导出聊天为公开内容的入口。
