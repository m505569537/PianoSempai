# S20 档案 Tab

- Screen ID: 见 Stitch 画布"档案"
- 本地参考图：`design/samples/S20-archive.png`
- Status: Final（第 3 tab 样图误作"电子琴"，按文案锁定修正）

## 用途一句话

长期成长档案：周统计、Neko 周观察、趋势图、take 时间线（可筛课程/奖励曲/自由），是月报与对比的入口。

## 视觉规范

- 三统计：等宽卡，数值 serif 28 tabular 琥珀，标签 label-sm muted。
- 周选择：描边胶囊下拉，切周仅本地查询。
- 观察卡：猫脸小图标 + body-md；末句自动生成时间 label-sm muted。
- 趋势卡：折线高 96，琥珀线 + 渐变底；手型占位行虚线边 muted"录像 3 条后展示"（不画假图）。
- 时间线：左 2pt 竖线（surface-high）+ 节点圆点（课程琥珀、奖励蓝灰、自由 muted）；行高 60，右侧 chevron；自由弹奏行无分数，显示音符数。
- 行点击 → S13（课程/奖励）或自由弹奏 take 回放（无报告）。

## 交互态

- 顶部右上或观察卡提供入口：「月度报告」→ S22；时间线多选模式 → S21 对比（仅同曲目同段两条可成功进入，不符时行内提示）。
- 空周："这周还没有有效练习（≥10 分钟且有 MIDI）"，无负罪文案。

## 红线落点

- 有效练习定义（有 MIDI 且 ≥10 分钟）；断签不惩罚、不显示"落后 N 课"（M9）。
- 手型不足时占位而非编造趋势。
