## 用途一句话

三段曲库浏览：训练教材（拜厄/哈农/599 按状态）、奖励曲库、全部导入；筛选 + 状态 + 导入入口。

## 视觉规范

- 顶部分段：三段等宽，选中段底部 2pt 琥珀指示器 + 文字琥珀，未选 muted；不要用 iOS 默认灰底分段。
- 筛选 chips：满圆角；教材 chip 单选（可再点取消），状态 chip 点开本屏小下拉（全部/未开始/练习中/已拿下）。
- 曲目行：高 56，左标题/副标（小节段、难度点），右侧状态区：已拿下=绿字+✓；练习中=琥珀字+脉动小点；未开始/锁=`#9C948B` + 锁形；未来教材行整体 0.5 透明 + "约 N 周后"。
- 导入虚线卡：1.5 琥珀虚线边 0.3 透明，中央 + 与格式说明，圆角 8。
- 行点击 → S09。

## 交互态

- 筛选切换：列表内容淡入 120ms；空筛选结果显示"这个筛选下还没有曲子"空态。
- 奖励曲库段：同样行样式，但来源标"手动导入"，无锁态（非公版）。
- 全部导入段：显示文件类型小图标（xml/mxl/mscz/mid）与导入时间。
- 点导入卡：系统文件选择器（Files/iCloud）；解析失败 → S-import-fail 弹窗。

## 红线落点

- 无商城/商店/市场/社区/下载盗版谱任何入口（不做清单红线）；PDF 导入不进此页（去 S10）。
