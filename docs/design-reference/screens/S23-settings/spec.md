## 视觉规范

- iOS 分组列表观感（Inset Grouped 暗色版）：组卡 surface，行间发丝，行高 48；左标题 body-md，右值 muted + chevron。
- 组标题 label-md muted 大写字距感（中文直接小标题）。
- 头像卡高约 96，头像 52 圆形琥珀描边。
- 危险/删除类行在子页内部，本页无红色行（Key 删除在 S25 内）。

## 交互态

- 未连接设备时首行变红点"未连接 · 去连接"→ S03。
- Key 未设置时该行琥珀高亮脉冲（唯一会脉冲的设置行）。

## 红线落点

- "隐私与六条红线"必须有独立可读页（v1 可用静态文本页，内容=PRD 六条红线原文）。
- 不出现账号、登录、云同步、会员、商店行。
