# S18b 视频裁切上传确认（Sheet）

- Screen ID: 见 Stitch 画布"裁切并发送给 Neko"（figaro 竖屏）
- 本地参考图：`design/samples/S18b-video-upload-sheet.png`
- Status: Final

## 用途一句话

任何视频离开本机前的唯一闸口：选区间、看大小、明示本次链路实际命中的服务商名、云端删除选项、用户确认。

## 视觉规范

- Sheet 高约 70%，同 S12 容器规范；时间轴：帧缩略条（深色）+ 双琥珀手柄，选区外压暗 60%。
- 区间信息 label-md tabular；快捷 chips 满圆角。
- 服务商卡：左缘 3pt 琥珀，body-sm；开关 ON=success 绿（语义是"更隐私"）。
- 确认按钮：在开关 OFF 时仍可点，但服务商卡展开额外红字"云端视频将保留到你在设置中清除"。

## 交互态

- 拖手柄实时更新时间/大小；区间最小时长 2 秒，错误提示用行内红字不用 Alert。
- 发送中：sheet 变进度态"正在上传 6MB 片段…"，可取消（取消即中止请求并本地删除缓存切片）。
- 失败：保留选区与问题，行内错误 + 重试。
- 发送完成：sheet 关闭，对话流出现视频消息；云端删除开关 ON 时，分析完成后气泡下显示"云端片段已删除 · 刚"。

## 红线落点

- 红线 4 的完整可视化：裁切 + 确认 + 本次实际命中服务商具名 + 删除选项，四要素缺一不可，文案不得弱化为"云端服务"，服务商名必须来自链路实时命中而非写死。
