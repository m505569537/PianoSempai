# S12 段落循环设置（Sheet）

- Screen ID: 见 Stitch 画布"段落循环设置"（figaro，780×1690 竖屏）
- 本地参考图：`design/samples/S12-loop-settings.png`
- Status: Final

## 用途一句话

从练习室拉起的底部抽屉：选循环小节段、循环方式（含速度自适应）、间隔与预备拍。

## 首屏布局

```
┌ 半透明天花板（scrim）
│ ┌────────────────────────────┐
│ │ 段落循环                  ✕  │ ← sheet 头，抓手条
│ │ 起点 17 [-][+]   终点 24 [-][+]│
│ │ ┌──────────────────────────┐│
│ │ │ 小节条带（32 格，17–24 琥珀，21 标记）││
│ │ └──────────────────────────┘│
│ │ [整段17–24] [只练21] [错点前后各2小节] [全曲]│ ← 快捷 chips
│ │
│ │ 循环方式（单选）              │
│ │ ◉ 逐遍循环（练完停 3 秒再来）   │
│ │ ○ 达标后自动 +5 BPM          │
│ │ ○ 崩了自动 −5 BPM（连崩 2 遍暂停，提示休息）│
│ │
│ │ 循环间隔    3 秒  [-][+]      │
│ │ [✓] 开始前 1 小节节拍器预备拍    │ ← 复选默认开
│ │
│ │ 〔取消〕   〔开始循环练习〕     │
│ └────────────────────────────┘
└ Home indicator
```

## 视觉规范

- Sheet：高约 78% 屏，顶部 12pt 抓手条（`#3D3531` 宽 36）；圆角顶 12；elevated 表面。
- 小节条带：32 等分窄格高 28；循环段琥珀填充，21 上方小三角标；未在段内 surface-low。
- 单选：16pt 圆，选中琥珀实心；行高 44。
- 底部按钮：左幽灵取消，右琥珀主按钮。

## 交互态

- 起/终点越界保护（1 ≤ 起 < 终 ≤ 总小节数），越界时步进器禁用变灰。
- 快捷 chip 与步进器双向联动。
- "连崩 2 遍"仅在选中自适应项时展开提示行（danger 描边卡，不选中时不占高度）。

## 文案锁定

- 三个循环选项、间隔、预备拍、连崩提示逐字。
