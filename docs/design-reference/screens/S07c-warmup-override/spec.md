# S07c 热身强开确认（Modal）

- Screen ID: 见 Stitch 画布"热身还没完成"（figaro 竖屏弹层）
- 本地参考图：`design/samples/S-gate-override.png`
- Status: Final（"Neko 周报"样图误作 Meiko，按文案锁定）

## 用途一句话

热身未完成想直接进主菜时的硬拦截：告知后果、必填原因标签、明示留痕，才可强开。

## 首屏布局（底部/中央卡片弹层，背景今日页虚化压暗）

```
│ scrim（今日页模糊 + rgba(12,10,9,.55)）
│ ┌────────────────────────────┐
│ │ 🔒 热身还没完成               │
│ │ 今天的热身还差 5 分钟。Neko 会把这    │
│ │ 次强开记在本周的 Neko 周报和月报里。  │
│ │ 这次强开的原因（必选一个）：       │
│ │ ◉ 时间不够，今天只弹主菜          │
│ │ ○ 手状态不错，跳过一次            │
│ │ ○ 热身曲太无聊                  │
│ │ ○ 其他（写一句）____________     │
│ │ ┌ 强开记录 ────────────────┐│
│ │ │ 本周第 1 次。记录只给你自己看，  ││
│ │ │ 不会影响任何解锁判定。        ││
│ │ └────────────────────────────┘│
│ │ 〔去补完热身（5 分钟）〕（默认焦点/主位）│
│ │ 我确认强开，开始主菜（琥珀，需先选原因）│
│ └────────────────────────────┘
```

## 视觉规范

- 卡片 elevated 表面，圆角 12，宽 350，内边距 20；锁图标琥珀（不是红色恐吓）。
- 原因单选同全局；选"其他"才展开输入框（未选时确认钮 disabled 灰）。
- 强开记录卡：琥珀 8% 底 + 琥珀左缘，body-sm。
- 双按钮上下堆叠：补完热身是描边次按钮（视觉优先建议项），强开是琥珀文字/填充按钮但位置在下。
- 弹层不可点击外部直接关闭（必须做选择）；可 ✕ 取消=回今日，不留记录。

## 交互态

- 确认后：写入 gate-override 事件（原因 + 时间戳），进练习室；今日热身卡标"今日已强开"。
- 本周 ≥3 次：卡片文案自动变"本周第 3 次，周报会提醒你留意热身习惯"（陈述不指责）。

## 红线落点

- 热身不可静默跳过（红线 6 当坏人）；但语气温柔、无 guilt 词（不写"你这样会受伤"等）。
- 强开绝不影响解锁判定，文案显式（红线 3 边界）。
