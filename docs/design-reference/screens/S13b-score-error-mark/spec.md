# S13b 标记疑似谱面错误（Sheet）

- 本地参考图：`design/samples/S-score-error-mark.png`
- Status: Final

## 用途一句话

同一小节连续弹成同一个音、与谱不符时，用户可标记"疑似谱错"：标记只挂数据、不扣分、不进过关失败。

## 首屏布局

```
│ scrim
│ ┌────────────────────────────┐
│ │ 标记疑似谱面错误            ✕ │
│ │ 拜厄45 · 第21小节 · 今天20:31的 take│
│ │ ┌ 纸白小谱条（红虚线圈住疑点音符）┐│
│ │ └────────────────────────────┘│
│ │ 你连续 3 遍都弹成了同一个音。可能是│
│ │ 谱子本身印错了，也可能是听谱习惯。 │
│ │ 这个标记不会扣分，也不会影响过关。 │
│ │ 哪里不对？                      │
│ │ [◉音符/和弦不对] [○节奏不对] [○指法标记可疑]│
│ │ 备注（选填）：[______________]   │
│ │ [✓] 之后这一小节的错音在报告中单列 │
│ │ 〔取消〕      〔提交标记〕       │
│ └────────────────────────────┘
```

## 视觉规范

- Sheet 同 S12 容器；纸白谱条高 96，红虚线 1.5 圈。
- 三类型 chip 单选，选中琥珀；复选同全局。
- 提交后 S13 错音清单中对应行变为"疑似谱错 · 已标记"琥珀标签，错音率计算将该行从分子中扣除（规则引擎行为，视觉仅展示标签与新数值脚注）。

## 交互态

- 入口：S13 错音行长按 / S11 标记按钮 / S09 谱错 ⚠。
- 同一小节重复提交合并计数（"已 2 人… 你自己 N 次"，自用产品即按次数显示）。

## 红线落点

- 显式"不扣分、不影响过关"（M2/M3 决策：疑似谱错与用户弹奏失败分开）。
