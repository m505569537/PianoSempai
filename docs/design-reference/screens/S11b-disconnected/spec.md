# S11b 练习室 · MIDI 断连态

- 本地参考图：`design/samples/S11-disconnected.png`（figaro 竖屏，226×512 缩略；以 S11 练习室为底的覆盖态）
- Status: Final

## 用途一句话

练习中 BLE/USB 断连时的全屏状态：判分暂停、谱区遮罩、可重连/诊断，重连续弹不丢音符。

## 首屏布局（在 S11 之上覆盖）

```
┌ 顶部全宽 danger 横幅
│ ● MIDI 已断开 · 判分已暂停   〔重新连接〕
│ 重连后从断点继续，不丢音符
│
│ 五线谱区压暗 + 居中遮罩卡：
│   〔断连图标〕
│   等待特伦斯 V70 重新连接…
│   （谱面内容仍隐约可见）
│
│ 走句进度暂停（不前进）；♩= 等控件置灰
│ 播放钮灰禁；结束钮灰禁
│ 〔打开 MIDI 诊断〕（幽灵）
└ 顶部连接胶囊同步变红"未连接"
```

## 视觉规范

- 横幅：`#C97064` 14% 底 + danger 文字/描边，高 44；「重新连接」描边 danger 小钮。
- 遮罩卡：`rgba(28,25,23,.72)` + 模糊，居中图标 32 muted；不销毁谱面与已录 MIDI。
- 置灰控件 opacity .4，禁用所有点击（节拍器例外，可继续出声打拍）。

## 交互态

- 点重新连接：调 CoreMIDI 重连，按钮 spinner；成功 → 横幅 1s 成功态"已重连，从断点继续"后淡出，续录；断线期间无判分，take 中标注断连区间。
- 10 秒未重连：横幅下追加一行"也可以检查：琴是否休眠 / 蓝牙距离"（不弹 Alert）。
- 用户仍可主动结束：二次确认"这段 take 缺少断开的部分，仍要保存吗"。

## 红线/事实

- 断连不算失败、不清零（M1 决策）；不使用"连接错误，请重试"吓人文案。
