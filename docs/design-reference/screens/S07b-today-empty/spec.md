## 视觉规范

- 英雄线稿同 S01 语言但更小（约 96pt）；柔光圆环琥珀径向 8%。
- 占位卡：三均等，label 两行 + 值 "—"（muted serif 28）。
- 定级内容提示：surface-low 卡 body-sm。
- 底部主按钮 + 幽灵按钮；未连接 MIDI 时主按钮仍可点（自评不需琴；到视奏步再引导连接）。

## 交互态

- 定级中途退出：下次进入主按钮变"继续定级（还剩 X 分钟）"。
- 逛曲库：切到曲库 tab（只读浏览，未解锁教材可看详情但练习 CTA 引导先定级）。
