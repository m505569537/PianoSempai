# PianoSempai · 竞品差距分析与功能优先级

> 日期：2026-10-09
> 方法：两路并行调研——西式主流 6 家（Simply Piano / Yousician / Flowkey / Skoove / Pianote·Musora / Piano Marvel）+ 中国市场 12 家（弹琴吧 / 完美钢琴 / The ONE / 小叶子 / 虫虫钢琴 / 懂音律 / 来音钢琴 / 泡泡钢琴 / 大猫 AI 陪练 / 掌门陪练 + Simply Piano / flowkey 中国区），随后对本仓代码逐点 grep 核查。
> 数据来源：各 app 官网、美区/中国区 App Store 官方元数据（iTunes API，版本截至 2026-09~10）、帮助中心、媒体报道。竞品确切价格部分未能全部取到（动态渲染页），引用时已标注。

---

## 1. 核心判断

PianoSempai 已具备三项**所有竞品（无论中西）都没有**的差异化能力：

1. **间隔重复复习（SRS，1/3/7/14 天调度）**——西式六家、国内十几家均无此功能。
2. **传统教材的成人自学路线**（拜厄 → 车尔尼 599 → 849，哈农并行）——国内产品要么做儿童考级、要么做纯娱乐瀑布流；Simply Piano/flowkey 有课程但不挂靠传统教材。
3. **Neko 人格化向导 + 硬门禁**——国内无对手，西式也只有卡通形象、无人格化向导。

因此局面不是"落后补课"，而是"护城河已成型，但主路径上有几个闭环没焊死"。问题集中在一句话：**分析做得出来，却没接到下一步行动**（裁判圈出了错题，却没有一键去练；诊断了病因，却不开药方）。

## 2. 竞品功能速览

### 西式 6 家
- **Simply Piano**：零基础引导最强；麦克风听音为主、MIDI 为辅；Soloist/Chords 双路线；5-Min Workouts、streaks、儿童 XP；与 Trinity College London 合作证书；已上 Vision Pro / Android XR。
- **Yousician**：游戏化鼻祖，1500+ missions；麦克风听琴给音准/节奏反馈；Weekly Challenge 全球比拼是核心留存。
- **Flowkey**：真人演奏手部视频 + 同步乐谱（竖屏可切整页传统乐谱，最接近读真谱）；Wait Mode（弹对才继续）/ Just Play；分手/Loop/慢速齐全；价格分层清晰（Premium $24.99/月、$149.99/年）。
- **Skoove**：明确"uses AI to listen"；USB/蓝牙/麦克风三种连接最全；1000+ 课；伴奏带 backing tracks；年付 $12.49/月。
- **Pianote（已并入 Musora）**：真人老师视频课（非瀑布判分）；主打"always know what to practice next"；大量 30-Day Challenge；可去任一乐器音轨；一会员通五乐器。
- **Piano Marvel**：最学院、曲库最大（25,000~30,000+ 首、18 级）；**SASR 视奏测评**是其最硬卖点；可上传任意曲目自建路径；$17.99/月、年付 $10.84/月。

### 中国市场要点
- **找谱/制谱 UGC 社区**是曲库根基：弹琴吧、虫虫钢琴、懂音律的"用户求谱 → 达人制谱 → 审核上架"闭环。
- **简谱生态**：五线谱一键转简谱（虫虫、懂音律）是核心卖点；西式完全不支持。
- **考级经济**：小叶子、大猫、The ONE 灯条深度绑定分级曲目/回课/考级预测。
- **真人陪练已被证伪**：VIP 陪练（2022）、快陪练（2021）、柚子练琴（2020）接连暴雷，行业全面转 AI 陪练。
- **软硬一体**：The ONE 跟灯琴/智能灯条把传统钢琴变智能。
- **成人自学是公认空白带**：要么儿童考级、要么纯娱乐瀑布流（泡泡钢琴，"以曲代功、兴趣优先"，28 元/月），传统教材成人路径无人系统化，正被 Simply Piano/flowkey 占据——正是本产品的定位窗口。

### 2024–2026 行业趋势
- "AI 听辨"把成熟的音高判别重新包装为 AI，已成营销标配（多为判别式，非生成式）。
- 麦克风声学判分下沉为"无 MIDI 也能用"，降低硬件门槛。
- 生成式 AI（对话陪练老师、AI 编曲、听曲识谱）在主流产品中**基本缺位**，被视为下一卖点但尚无标杆——留出差异化空间。
- 平台化（多乐器/多 app 会员）、XR 抢位、"明确下一步 + 每日路径 + 30 天挑战"的带练教练化。
- 严肃/学院化回潮：读真谱/视奏/古典体系重新被重视，与本产品传统教材路线同向。

## 3. 本产品的功能缺陷（闭环断点，均有代码实证）

| # | 缺陷 | 证据 |
|---|---|---|
| D1 | **一键"只练错误热点"未接通**：数据已落库（`TakeAnalysis.hotspotMeasures`），但循环设置里热点模式被判为无真实数据源 | `S12LoopSettingsSheet.swift:543` `hasRealSource` 对 hotspot 返回 false；`PieceDetailView.swift:224`、`TodayView.swift:544` 仅留注释 |
| D2 | **"如何获得可练谱"指引页承诺但不存在** | PRD:101 要求；Features 目录无任何 Guide/Help/HowTo 视图（grep 零结果） |
| D3 | **只诊断不开药方**：无"错误类型 → 矫正练习"映射 | 全工程 recommend/drill/矫正 零结果；PRD M3"连续不过插针对性练习"无引擎支撑 |
| D4 | **视奏仅定级当天测一次**：自学党最易藏拙的读谱能力缺日常训练 | `SightReadSession` 仅在 Onboarding/S04 使用，无日常入口（对标 Piano Marvel SASR） |
| D5 | **奖励曲难点段落混进热身未实现** | PRD M3 Q4=A 承诺；grep 仅有任务类型字段，无分析/混入逻辑 |

### 战略级矛盾（需产品拍板，头号问题）
产品定位"PDF 谱为主"，用户最有热情、最常弹的久石让/坂本龙一也基本只有 PDF；但练习室的纠错/变速/分手/判分只吃 MusicXML。结果是**最常弹的曲子恰好用不上最强的功能**。OMR（PDF 自动转谱）是红线且技术不可靠，不碰；改为分层缓解：
- 短期：把"如何获得可练谱"做扎实（在哪找现成 MusicXML、Mac 端 MuseScore 十分钟转换、导回 app），把摩擦降到最低。
- 中期：检测 PDF 同目录同名 .mid/.musicxml 自动关联等衔接优化。

## 4. 建议新增功能与优先级

### P0 —— 成本小、直接打通主路径
- **P0-1 可练谱获取指引页**（D2 + 战略矛盾短期解）。
- **P0-2 接通一键"只练错误热点"**（D1）：把最近一次 `TakeAnalysis.hotspotMeasures` 喂给 LoopService，数据现成、主要是接线。

### P1 —— 补全教学闭环、加深护城河
- **P1-1 错误类型 → 矫正练习处方引擎**（D3）：错误分类映射教材条目/针对性小节，连续不过自动插。
- **P1-2 日常视奏训练**（D4）：复用 SightReadSession，做成今日可选项 + 命中率趋势（对标 SASR）。
- **P1-3 奖励曲难点自动混入热身**（D5）。
- 备注：M6 视觉手型在既定 P4 路线上，非新增，按原计划推进。

### P2 —— 有余力再做，均需先 Grill
- **P2-1 轻量练耳/视唱**（听音辨音程、节奏型模仿）：比单纯乐理课更对症读谱短板。
- **P2-2 简谱层**：本人会简谱、国内成人也靠简谱；但 PRD P1 明确不做，属后置反转，需专门议。
- **P2-3 连续达标周数等轻激励补全**：现 WeekStreak 诚实留白、无数字。
