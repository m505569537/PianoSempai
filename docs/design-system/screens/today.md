## 门禁规则（M3/M9）

- 有效练习：有 MIDI 且 ≥10 分钟（streak 灯/周报唯一口径）。
- 热身 8–12 分钟，不可静默跳过；强开走 S07c：原因四选一（其他必填一句），写 GateEvent(kind=override)；本周第 N 次计数；月报可见；**不影响任何解锁**。
- 到点不截断：弹完当前小节自动保存。
- 断练回归：今日页不出现"落后/补课"文案；复习池低风险任务优先（课程引擎行为）。
