# ADR-0008 — 听音辨音程（轻量练耳，G6 首批）

- 状态：accepted
- 日期：2026-10-10
- 关联：竞品差距 G6（docs/competitive-gap.md P2-1）；成人读谱短板对症，纯绿地（grep 实证仓库无任何练耳/视唱/乐理代码）。

## 背景

竞品调研结论：轻量练耳「比单纯乐理课更对症读谱短板」。P0/P1 五项与 G8 清零后，G6 列入。本仓已有可复用发声地基：

- `DemoPlaybackService`（整曲示范；底层 `SamplerSynthBackend`：AVAudioEngine + AVAudioSequencer + 随包 MuseScore_General.sf2 钢琴音色）。
- `SineBeepAudioUnit.triggerNote(note:velocity:)`（直发单音）。
- 选择哪个用于音程题由 Stage 实现按可复用性决定（倾向最小的单音播放器，避免整套 sequencer 起停开销）。

## 决策（两轮 Grill 8 项用户口径 + 第三轮超时项取推荐默认，均标注）

1. **首批只做听音辨音程**：纯听 + 屏幕点选，不做节奏模仿（二期）、不做视唱/唱名（需麦克风，app 红线不做麦克风听音）。
2. **选择题作答**：屏幕点音程名，不需要琴，随时能练。
3. **独立新入口**：放在「我的」页（SettingsView 工具行聚集地，不干扰练习）。〔第三轮超时·取推荐默认，可改练习 tab〕
4. **难度跟课程进度挂钩**：随拜厄进度自动解锁，不做独立升级曲线。
5. **音程范围**：一个八度内 13 种（小二度 1 → 纯八度 12 半音），随拜厄进度分批解锁，不出复音程。
6. **只弹上行旋律音程**：先后两个音、从低到高；首批不做下行/和声音程。
7. **4 个选项，用音程中文名**：小二度/大二度/小三度/大三度/纯四度/增四度/减五度/纯五度/小六度/大六度/小七度/大七度/纯八度（4 选 1，含 1 个正确 + 3 个同已解锁集合内的干扰项）。
8. **每轮 10 题，记录命中率 + 趋势**：复用 G4 视奏那套轻量统计（一轮一条记录、升序、最近 N 轮柱状趋势）。
9. **答错反馈**：选错立即高亮正确答案 + 可「再听一次」，然后进下一题。〔第三轮超时·取推荐默认〕
10. **设备要求**：无需连琴/耳机，app 自己发声、屏幕点选，随时可练。〔第三轮超时·取推荐默认〕

## 实现口径

新增内容（允许新增文件，因是新模块；交付后由 Hermes `xcodegen generate` 纳入工程）：

核心纯逻辑（可测、与音频/UI 解耦）：
- `IntervalID`：13 种枚举（半音数 1...12 + 中文名）。
- `IntervalUnlock.allowedIntervals(currentBeyer:)`：按拜厄条目号返回当前已解锁半音数集合。解锁阶梯（实现给常量、Stage 可据拜厄进度微调）——
  入门（拜厄 ≤ 30）：{大二度 2, 小三度 3, 大三度 4, 纯五度 7, 纯八度 12}（最协和、最常出现）；
  进阶（31–60）：+{小二度 1, 纯四度 5, 大六度 9, 小七度 10}；
  后期（>60）：+{增四度 6, 减五度 6, 小六度 8, 大七度 11}（全开）。
  注意增四度与减五度同半音数（6）但听感/命名不同：选择题选项去重，同一半音数只呈现一个名称（首批用「三全音」单一标签或按出现语境，避免两个正确答案）。
- `IntervalQuiz.makeQuestion(allowed:)`：随机根音（限制在中央 C 附近约一个八度窗口，保证第二音 ≤ 该八度），随机选一个已解锁半音数为正确项；4 个选项 = 正确 + 3 个从已解锁集合取的不同干扰项。确定性可注入随机源（测试用固定种子）。
- 判定：作答半音数 == 正确半音数。
- 记录/趋势：新增 @Model（如 `EarTrainingRound`：date/正确数/总数/题型=interval），store 一轮一写、幂等；趋势纯函数（最近 20 轮命中率升序）。口径对齐 G4，不写 Take/TakeAnalysis、不触发过关/课程推进/streak。

播放：新增最小 `IntervalTonePlayer`（复用现有钢琴音色/SamplerSynthBackend 或 triggerNote），依次弹根音→冠音（如各 0.6s、间隔 0.25s），支持「再听一次」。具体复用哪条路径在 Stage 实现时选已存在的、避免新建第二套音频引擎。

UI：
- 「我的」页新增一行入口（icon + 「听音练耳」+ chevron），fullScreenCover 打开。
- 练耳页：标题（第 n/10 题）、「播放/再听一次」按钮、4 个音程名选项竖排；未作答前选项中性，作答后正确项高亮、错选项标红；一题结束出「下一题」。
- 10 题结束：本轮命中率 + 最近轮次柱状趋势（复用 G4 趋势样式或简化）。

非目标：不做节奏模仿、视唱、和声音程、下行音程、复音程；不改 Piece/Take/课程状态；不影响任何既有模块。

## 验证

- 纯逻辑单测：解锁阶梯（拜厄 0/30/31/60/61 各档集合）；makeQuestion 根音+半音数落在八度内、4 选项含唯一正确、干扰项均已解锁（固定种子确定性）；判定正/负；三全音单标签无两个正确答案；记录/趋势（升序、命中率）。
- 独立全新全量 xcodebuild test（先 xcodegen 纳入新文件），总数在 700 基础上 +新增测试、0 failures。
- 发声听感属真机/音箱项（模拟器能出声验证不报错即可，音色不评判）。
